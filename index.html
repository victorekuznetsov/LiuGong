Каталог запасных частей LiuGong

Слева — разделы каталога, внутри каждого узлы. Откройте узел: рядом с чертежом появится список позиций. Номер позиции на чертеже кликабельный — щелчок по нему подсвечивает строку таблицы, щелчок по строке подсвечивает номер на чертеже. Щелчок по номеру детали открывает карточку: паспорт из EPC, фотографии, цена по прайс-листу, цепочка замен и все узлы всех каталогов, где эта деталь применяется.
